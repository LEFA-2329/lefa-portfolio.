# Study Packs pilot

The public /learn/study-packs/ page is generated by scripts/build-studylab-search-pages.mjs. It previews an original Database Revision Pack and links to a five-page free sample and two database setup scripts. The complete pack is not published in dist or this public repository. Do not add the private workbook, worked answer book, exam, marking guide, editable source or private ZIP to the public build.

The complete private pilot contains 24 SQL exercises, 6 normalisation cases with diagrams, a 100-mark mock exam and a separate marking guide. Existing free programming and database downloads are preserved. The preview is linked from the application sidebar, download pages and public guide header. It has no payment buttons, registration, tracking service or backend dependency.

The sample's schema has 20 students, 6 courses and 23 enrolments, including repeated names, missing marks and unmatched parents. Setup scripts reset four named tables and must be run in an empty practice database. Automated checks exercise dataset constraints and join edge cases.

Before commercial release, run all native T-SQL answers on a real SQL Server instance, obtain volunteer feedback, check the 100-mark rubric and approve the final content. SQLite equivalents do not validate native SQL Server procedures, OUTPUT or TRY/CATCH. No payment or protected-download system has been enabled.
