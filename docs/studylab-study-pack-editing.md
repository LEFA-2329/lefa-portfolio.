# Editing the public study packs

The public downloads are separate from the private premium bundle.

- `scripts/study-packs/teaching-chapters.json`: five free teaching chapters per module, examples and check questions.
- `scripts/study-packs/free-revision-questions.json`: the short independent practice set and explained answers.
- `dist/learn/images/study-packs/`: labelled teaching figures and revision cover previews.
- `scripts/build-module-study-packs.py`: generates the guide, questions and answers PDFs, creates deterministic ZIP bundles and writes the resource catalogue.
- `scripts/module-study-packs.json`: generated names, file sizes, page counts and slide counts. Do not hand-edit it.
- `dist/learn/downloads/modules/*-Illustrated-Revision.pptx`: maintained editable public decks. Edit them in PowerPoint, validate layout, then replace the matching PDF slide copy and preview when changed.
- `scripts/build-studylab-search-pages.mjs`: public library page layout and download links.
- `dist/learn/css/study-pack-library.css`: the resource page styles.

Install the Python packages in `requirements.txt`, then run `npm run build` to rebuild the named PDFs and resource page. The browser needs no Python. PowerPoints are checked-in public source files, not generated by the routine website build. Keep the full premium exams, extended task banks and private project archives outside `dist`.

Existing Markdown and ZIP download URLs remain as legacy files for compatibility. They are no longer the primary downloads shown to students.

PRLD5121 now uses the full current course and dedicated extension data. See [PRLD5121 coverage and editing](prld5121-content-coverage.md) for its 25 chapters, 78 tasks, mixed papers and Word copies. The other modules retain their five-chapter revision sources.
