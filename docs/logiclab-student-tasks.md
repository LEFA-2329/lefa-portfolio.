# Student task library and interface refresh

Adds 35 practice tasks alongside 44 lesson tasks, for 79 total. Adapted from the supplied modularisation, methods, loops, parallel-array and revision materials. Duplicate task sheets and repeated methods questions are consolidated. The HTML login mock is outside this PRLD module. Image-dependent and ambiguous exam questions are not reproduced. Original exam PDFs and institutional assessment instructions are not published. The contribution scenario is explicitly fictional and is not presented as payroll guidance.

Topics: Methods, Overloading, Loops, Parallel arrays, Revision and OOP. Students can search and filter by topic or difficulty, write session-local drafts, submit an attempt, reveal a model solution and copy their work. Suitable pseudocode tasks can carry student code into the diagram lab. OOP, overloaded-method and explanatory tasks are labelled written practice. No automatic grading of free text is claimed.

The dashboard completed-lessons card is removed without deleting stored progress. Sidebar progress is retained. Teal and blue replace purple; typography, controls and mobile layouts are made larger, and a three-step learning guide is added.

Validation: node tests/logiclab-expansion.test.mjs and node tests/logiclab-student-tasks.test.mjs.
