## Make an edit in VS Code

1. Open the repository folder in VS Code. Use the Explorer panel on the left.
2. Open the HTML or lesson file from the table. Change a heading, explanation or question.
3. Run `npm run format`, then `npm run build`, then `npm test`.
4. Preview using a local web server. Do not open index.html using a file:// URL; JavaScript modules need HTTP.
5. Commit the source and generated HTML module together. Push to main to deploy through GitHub Pages.

Run `npm ci` once if formatting dependencies are missing. The website itself is still a static site; npm is used for editing and checks, not for a server in production.

## Why some content is still in .mjs files

An `.mjs` file is a JavaScript module. Questions, lesson data and interactive logic belong in these files. `.html` files now hold the larger page layouts so you can find headings, buttons and sections directly.

A placeholder such as `{{dynamic_1}}` marks a section filled by the matching page script. Edit the surrounding HTML freely; keep placeholder names, element IDs and data attributes intact unless you update their script too. The first comment in each HTML file names the function that supplies those sections.

`dist/shared/compiled-html-pages.mjs` is generated by `npm run build`. Edit its matching HTML source, not that generated copy. Tests reject an outdated generated copy, so it cannot accidentally publish without your HTML changes.
